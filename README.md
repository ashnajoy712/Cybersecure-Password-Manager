# CyberSecure Password Manager

A Python-based cybersecurity project designed to securely manage passwords and credentials.

## Features

- Password strength analysis
- Secure password generation
- Master password authentication
- Encrypted password vault
- Add and delete credentials
- Password retrieval
- Security audit logging
- Vault locking

## Technologies

- Python
- Cryptography
- Scrypt
- Fernet Encryption
- JSON

## How to Run

Install the required library:

pip install cryptography

Run the application:

python password_security.py

## Cybersecurity Concepts

- Authentication
- Encryption
- Key derivation
- Secure password generation
- Access control
- Security auditing
